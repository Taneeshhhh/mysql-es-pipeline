# MySQL to Elasticsearch Pipeline

Architecture:

MySQL
   ↓
Python ETL Script
   ↓
Elasticsearch
   ↓
Grafana Dashboard

Features
Fetches data from MySQL
Converts relational rows into ES documents
Indexes into Elasticsearch
Visualized through Grafana


Tech Stack
Python
MySQL
Elasticsearch
Grafana

Setup

Commands:

create venv
install requirements
run elasticsearch
run kibana
run grafana
run script
